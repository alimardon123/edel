# Instructions for coding agents

This repository keeps its agent instructions in `CLAUDE.md` files. They apply to every coding agent, not only Claude.

1. Read [CLAUDE.md](CLAUDE.md) at the repository root before doing anything. It holds the project, the ranked principles, the decisions already taken, the commands, how work flows and what waits for Alimardon.
2. Before editing in `docs/`, `crates/edel/`, `ci/` or `images/`, read the `CLAUDE.md` in that directory too.

Keep one source: change the rules in the `CLAUDE.md` files, never here.

# Backports

Generated by `edel image deps` from the images' package lists (roadmap M8.10b): do not edit it by hand. CI's build makes it again and fails when it differs; copy the file from the run's summary.

Alpine's main repository gets fixes for about two years, its community repository only until the next stable branch, about six months. For every base package below, which comes from community, we backport security fixes ourselves for the full two years of a base release (ADR-003). Keeping the base small keeps this list short.
